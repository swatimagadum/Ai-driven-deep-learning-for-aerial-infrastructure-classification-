Technical System Documentation

Comprehensive architectural and technical reference manual for the Aerial Infrastructure Intelligence Platform.

1. Project Overview & Problem Statement

Problem Statement: Manual interpretation of vast satellite and drone aerial imagery is labor-intensive, slow, and prone to human oversight during critical infrastructure monitoring and defense operations.

Proposed Solution: An automated, end-to-end Deep Learning intelligence system that processes aerial images through an integrated pipeline:
Image Input → Image Quality Check → Preprocessing → Transfer Learning CNN Classification → AI Explainability Heatmap → Infrastructure Intelligence → Risk/Priority Score → PDF Report Export

2. Technology Stack

Python 3.14 Flask Web Framework TensorFlow / Keras DenseNet121 Architecture VGG16 Architecture MobileNetV2 Architecture Pillow (PIL) Image Processing SQLite3 Database HTML5 / CSS3 / JavaScript Cyberpunk Glassmorphism UI

3. Image Preprocessing & Normalization

  • Image Resizing: Resizes input images to 224 × 224 × 3 pixels to match CNN input tensor dimensions.
  • Color Space Standardization: Converts all images to standard 3-channel RGB.
  • Pixel Value Normalization: Scales pixel intensity values from [0, 255] to [0.0, 1.0] by dividing by 255.0 to maintain stable gradient calculations during backpropagation.

4. Model Architectures & Transfer Learning

The project evaluates three pre-trained Convolutional Neural Network (CNN) architectures:

  • DenseNet121 (Winning Model - 97.40% Accuracy): Utilizes dense connectivity where each layer receives direct inputs from all preceding layers, maximizing feature reuse.
  • VGG16 (94.20% Accuracy): Deep 16-layer architecture with 3×3 convolution filters for strong spatial feature extraction.
  • MobileNetV2 (92.10% Accuracy): Lightweight architecture using depthwise separable convolutions optimized for low-latency drone edge devices.

5. AI Explainability & Risk Priority Scoring

AI Explainability: Generates region-of-interest activation heatmaps (heatmap_.png) pointing out structural feature hotspots (runways, girders, circular tank walls).

Infrastructure Priority Score (0–100): Calculates a transparent monitoring priority score based on baseline infrastructure criticality, model confidence rating, and image quality parameters.

6. System Limitations & Future Scope

Limitations: Does not perform actual structural damage analysis; relies on classification-based priority scoring.

Future Scope: Integration of real-time EXIF GPS drone telemetry, multi-spectral satellite imagery processing, and automated damage detection models.
