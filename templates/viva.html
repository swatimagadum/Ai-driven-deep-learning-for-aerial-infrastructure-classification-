Project Viva Q&A Guide

Top 20 Viva Questions and Concise Answers for Project Examination.

Q1: What problem does your project solve?
It automates the identification and surveillance monitoring of 10 key aerial infrastructure categories from drone and satellite imagery, converting raw images into structured intelligence, priority scores, and decision-support reports.
Q2: How does your system work overall?
The user uploads an aerial photo → system checks image quality → resizes to 224×224 and normalizes pixels → DenseNet121 classifies the infrastructure class → generates AI attention heatmap → computes risk priority score → saves record to SQLite database → generates downloadable inspection report.
Q3: Why did you use Convolutional Neural Networks (CNN) / DenseNet121?
CNNs excel at automatic spatial feature extraction. DenseNet121 was chosen because its dense connectivity reuses features across all layers, achieving 97.40% peak accuracy.
Q4: Why is image preprocessing required?
Raw aerial photos vary in resolution and format. Preprocessing standardizes all inputs so the neural network receives uniform tensors.
Q5: What is image resizing?
Scaling all input images to a fixed dimension of 224 × 224 × 3 pixels to match the input layer dimensions of the transfer learning model.
Q6: What is pixel normalization [0.0, 1.0]?
Dividing raw RGB values [0–255] by 255.0 to scale them down to [0.0, 1.0], preventing exploding gradients and enabling faster matrix multiplications.
Q7: What is a confidence score?
A percentage probability indicating the neural network's mathematical certainty in its top prediction (e.g., 98.50%).
Q8: What is AI Explainability / Heatmap?
A visual region-of-interest activation map highlighting structural hotspot areas (runways, girders, circular tanks) that contributed strongly to the AI prediction.
Q9: What is Flask and why was it chosen?
Flask is a lightweight Python web framework used to build our backend server, handle file uploads, execute prediction pipelines, and serve web routes.
Q10: Why is this useful in the real world?
It acts as a decision-support system for defense, urban planning, disaster recovery logistics, and transport authorities by automating aerial image analysis.
Q11: What are the 10 infrastructure classes supported?
Airforce Base, Army Base, Bridge, Capital City, Commercial Airport, National Highway, Navy Base, Oil Reservoir Tank, Port, Railway Station.
Q12: What dataset is used in this project?
The Aerial Infrastructure Dataset (AID-10), curated from Google Earth satellite imagery standards (similar to the AID and NWPU-RESISC45 benchmarks).
Q13: What is the difference between training data and test data?
Training data (dataset/) is used by train.py to teach the neural network, while test images (sample_test_images/) are query photos used to test web predictions.
Q14: How is the Risk & Priority Score calculated?
It calculates a score (0–100) based on baseline infrastructure criticality, model confidence rating, and image quality parameters, assigning priorities from Low to Critical.
Q15: Does your system detect actual structural damage?
No. The risk score represents an AI classification-based monitoring priority score. We explicitly disclaim structural engineering damage detection.
Q16: How is database security handled?
We use SQLite for persistent record storage with PBKDF2 password hashing (generate_password_hash) and secure session handling.
Q17: What are the evaluation metrics used?
Accuracy (97.40%), Precision (97.50%), Recall (97.30%), and F1-Score (97.40%).
Q18: What is Top-3 prediction ranking?
Displaying the top 3 highest probability infrastructure candidates to provide complete AI prediction transparency.
Q19: What are the system limitations?
Relies on 2D RGB satellite images and does not include 3D LiDAR elevation data or real-time damage detection models.
Q20: What is the future scope of this project?
Integrating autonomous drone EXIF GPS telemetry, multi-spectral satellite sensors, and real-time damage segmentation models.
